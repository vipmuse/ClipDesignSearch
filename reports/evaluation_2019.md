# 디자인 도면 검색 성능 평가 보고서 (2019 held-out)

**작성일:** 2026-07-10
**대상 모델:** MetaCLIP 2 (worldwide-huge) + LoRA 어댑터 (`outputs/lora-clip-design/final`)
**평가 스크립트:** `src/evaluate_retrieval.py`

---

## 1. 목적

정답(유사 이미지 쌍) 라벨이 없는 상황에서 디자인 특허 도면 **유사도 검색** 성능을
정량 평가하고, **학습 효과**와 **분류(로카르노) top10 기능**의 타당성을 검증한다.

## 2. 평가 데이터: 2019 (완전 미학습, held-out)

| 항목 | 값 |
|------|-----|
| 출처 | DeepPatent2 (Harvard Dataverse), 2019년 |
| 전체 | 96,025 도면 / 12,043 디자인 |
| **평가 샘플** | **24,182 도면 / 3,000 디자인** (디자인 단위 무작위 추출, seed=42) |
| 학습 사용 여부 | ❌ 미사용 (모델은 2010+2020으로만 학습) |

> 2019는 학습에 전혀 쓰이지 않았으므로, 아래 수치는 **일반화(generalization) 성능**이다.

## 3. 평가 방법론 — 정답 라벨 없이 평가하기

디자인 도면에는 "이 둘이 유사하다"는 수작업 정답이 없다. 대신 **데이터에 내재된 신호**를
정답으로 활용한다.

### A. 같은-출원 검색 (self-supervised ground truth)
한 출원(`design_id`, patentID)의 여러 도면은 **같은 디자인의 다른 뷰**(정면/측면/사시도…)다.
따라서 쿼리 도면에 대한 **"정답 유사 이미지 = 같은 출원의 다른 도면"** 으로 정의한다.
(DeepPatent 논문의 retrieval 평가와 동일한 원리.)
- **Recall@K**: 상위 K개 안에 같은 출원 도면이 1개 이상 있는 쿼리 비율
- **mAP**: 같은 출원 도면들을 순위 상단에 얼마나 잘 모으는가 (상위 200 기준)

### B. 같은-로카르노 검색 (카테고리 relevance)
같은 로카르노(과, 예: `06-01` 의자)는 **같은 물품 카테고리**다. relevant = 같은 로카르노.
- **P@10**: 상위 10개 중 같은 로카르노 비율
- **mAP**: 카테고리 정렬 품질 (상위 200 기준)

### C. 분류 top10 정확도 (기능 검증)
웹앱의 "분류 top10"은 유사도 상위 도면들의 로카르노를 **유사도 가중합**으로 집계한다.
쿼리의 **실제 로카르노**가 그 top1/top3에 들어오는지로 기능을 검증한다.
- **top1_acc / top3_acc**: 가중 1위 / 상위 3위 안에 실제 로카르노가 포함된 쿼리 비율

## 4. 결과 (학습 전 baseline → 학습 후)

### A. 같은-출원 검색
| 지표 | Baseline (학습전) | **Trained (학습후)** | 개선 |
|------|:---:|:---:|:---:|
| R@1  | 0.737 | **0.805** | +6.8pp |
| R@5  | 0.835 | **0.893** | +5.8pp |
| R@10 | 0.862 | **0.913** | +5.1pp |
| mAP  | 0.307 | **0.416** | +10.9pp |

### B. 같은-로카르노 검색
| 지표 | Baseline | **Trained** | 개선 |
|------|:---:|:---:|:---:|
| P@10 | 0.449 | **0.545** | +9.6pp |
| mAP  | 0.102 | **0.162** | +6.0pp |

### C. 분류 top10 정확도
| 지표 | Baseline | **Trained** | 개선 |
|------|:---:|:---:|:---:|
| top1 정확도 | 0.489 | **0.562** | +7.3pp |
| top3 정확도 | 0.718 | **0.795** | +7.7pp |

## 5. 해석

- **모든 지표가 학습으로 개선**되었고, 미학습 2019 기준이므로 과적합이 아닌 **실질적 일반화 향상**이다.
- **같은-출원 R@1 = 0.805**: 임의의 도면을 쿼리했을 때 top-1 결과가 **80.5% 확률로 같은 출원의 다른 뷰**.
  정답 라벨이 없어도 유사도 검색 성능을 신뢰성 있게 측정할 수 있음을 보여준다(§3-A 방법의 유효성).
- **분류 top10 top3 정확도 = 0.795**: 분류 top10에 **진짜 카테고리가 80% 확률로 포함**됨 →
  "분류 top10" 기능이 실제로 유의미하게 동작함을 검증.
- **B의 mAP가 낮은 이유**: 로카르노 한 과의 멤버가 수백~수천 개라 mAP 분모가 커서 원래 낮게 나온다.
  카테고리 품질은 **P@10(0.545)** 로 보는 것이 적절하다.

## 6. 한계 및 다음 단계

- 같은-출원 정답은 "같은 디자인 재검색"을 측정하며, **서로 다른 디자인 간의 시각적 유사도**는
  직접 측정하지 못한다(그건 본질적으로 주관적). 필요 시 소량의 인적 평가(정성)로 보완 가능.
- 평가는 3,000 디자인 샘플 기준. 전체(12,043) 또는 다년도로 확장하면 신뢰구간이 좁아진다.
- **2019까지 포함해 재학습** 후 본 baseline 대비 재평가하면 데이터 확대 효과를 정량화할 수 있다.

## 7. 재현 방법

```powershell
# 1) 2019 다운로드 + eval pairs 생성
python scripts\download_deeppatent2.py --years 2019
python scripts\build_pairs.py --src models\deeppatent2\extracted\2019 --out data\eval_2019.jsonl

# 2) 평가 (GPU 필요 → 웹서버는 내려둘 것)
python src\evaluate_retrieval.py --adapter outputs\lora-clip-design\final --data data\eval_2019.jsonl --image-root . --designs 3000
python src\evaluate_retrieval.py --base --data data\eval_2019.jsonl --image-root . --designs 3000
```

> 모델은 2010+2020 학습(5000 스텝, batch 32). 상세 설정은 `configs/lora_clip.yaml`, `SETUP.md` 참고.
